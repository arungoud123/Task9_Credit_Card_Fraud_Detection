# Task 9 – Credit Card Fraud Detection

This project uses Random Forest algorithm to detect fraudulent credit card transactions.

## Objective
To build a classification model that identifies fraud transactions.

## Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  

## Steps Performed
- Loaded dataset  
- Preprocessed data  
- Split into training and testing sets  
- Trained Random Forest classifier  
- Evaluated model performance  

## Output
Model predicts whether a transaction is fraudulent or not.
